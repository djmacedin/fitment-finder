# Fitment Finder v2

Static mobile-first UK/EU wheel and tyre reference prototype. Uses 16 **unverified starter reference** vehicle-generation records adapted from the existing Car Fitment Cheat Sheets project. These are not authoritative fitment specifications.

## Deploy to GitHub Pages

Upload `index.html` and `data.js` to the root of the `main` branch of `djmacedin/fitment-finder`, replacing the old files. The existing GitHub Pages site will update automatically. Do **not** upload the ZIP itself.

## Features

- Make, model, year and generation cascading selection.
- Wheel PCD, hub bore, fastener and example OEM wheel/tyre sizes.
- Reverse PCD lookup with optional wheel centre bore screening.
- Responsive layout, accessible labels and warnings.

## Limitations

No verified VIN, trim, brake, axle, offset compatibility, TPMS or parts cross-reference. The reverse lookup lists candidates only, not guaranteed compatibility. Year ranges overlap across generations. Do not rely on this data alone for purchase, installation or road safety decisions.
